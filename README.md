# Sistema de Análise de Vagas Tech — versão RAD em Python

O projeto é uma plataforma de análise de vagas de emprego que permite importar, cadastrar, consultar, editar e excluir oportunidades profissionais. O sistema oferece filtros de pesquisa, comparação de vagas, dashboard com indicadores e gráficos, além de relatórios sobre tecnologias mais demandadas e estatísticas salariais. Desenvolvido em Python com interface Tkinter e banco de dados SQLite, também permite sincronizar vagas do Supabase para manter os dados atualizados.
